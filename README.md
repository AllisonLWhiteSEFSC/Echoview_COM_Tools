## About
A collection of Python scripts and Jupyter notebooks for automating Echoview workflows via the Windows COM interface.

## Prerequisites
* **Operating System:** Windows (required for Echoview COM automation)
* **Software:** Echoview (with active license including automation module) & Python 3.10+
* **Key Python Packages:** `pywin32`, `PyAutoGUI`

## Repository Structure
* `scripts/` — Standalone `.py` scripts for batch processing and COM automation
* `notebooks/` — Interactive Jupyter notebooks (`.ipynb`) with step-by-step examples
* `data/samples/` — Small sample files for testing workflows
* `docs/` — Source files for the project's GitHub Pages documentation
